# 11 — Assets and Icons

## Asset Directory Structure
```
assets/
├── branding/          # School-specific; replaced per flavor before build
│   ├── app_icon.png   # 1024x1024 source (used by flutter_launcher_icons)
│   ├── app_logo.png   # Used in-app (login screen, splash, drawer header)
│   └── splash_logo.png # Splash screen logo
├── icons/             # App feature/UI icons (SVG preferred)
│   ├── ic_student.svg
│   ├── ic_staff.svg
│   ├── ic_timetable.svg
│   ├── ic_attendance.svg
│   ├── ic_fees.svg
│   └── ic_communication.svg
├── images/            # Static JPG/PNG imagery
│   └── onboarding_bg.png
├── fonts/             # Custom font files
│   ├── Inter-Regular.ttf
│   ├── Inter-Medium.ttf
│   └── Inter-Bold.ttf
└── lottie/            # Lottie animation JSON
    ├── loading.json
    └── success.json
```

## Asset Constants (core/constants/asset_constants.dart)
All asset paths are constants. Never hardcode 'assets/icons/ic_student.svg' in widgets.
```
class AssetConstants {
  // Branding
  static const String appLogo = 'assets/branding/app_logo.png';
  static const String splashLogo = 'assets/branding/splash_logo.png';

  // Icons
  static const String icStudent = 'assets/icons/ic_student.svg';
  static const String icStaff = 'assets/icons/ic_staff.svg';
  static const String icTimetable = 'assets/icons/ic_timetable.svg';

  // Lottie
  static const String lottieLoading = 'assets/lottie/loading.json';
  static const String lottieSuccess = 'assets/lottie/success.json';
}
```

## SVG Support
Use flutter_svg package.
```
SvgPicture.asset(AssetConstants.icStudent, width: 24, height: 24, colorFilter: ...)
```

## App Icon Generation
Use flutter_launcher_icons package.
Source file: assets/branding/app_icon.png (1024x1024, no rounded corners — OS applies rounding)
Configuration in pubspec.yaml per flavor:
```yaml
flutter_launcher_icons:
  android: true
  ios: true
  image_path: "assets/branding/app_icon.png"
  adaptive_icon_background: "#FFFFFF"
  adaptive_icon_foreground: "assets/branding/app_icon.png"
```
Run: flutter pub run flutter_launcher_icons

For multi-school:
- Replace assets/branding/app_icon.png with the school's icon
- Rebuild app icons
- Build the flavor

## Splash Screen
Use flutter_native_splash package.
School logo placed in assets/branding/splash_logo.png.
Background color from school theme config.

## iOS App Icon
Generated by flutter_launcher_icons into ios/Runner/Assets.xcassets/AppIcon.appiconset/.
Required sizes are generated automatically from the 1024x1024 source.
No manual Xcode configuration needed when using the package.

## Android Adaptive Icons
Generated into android/app/src/main/res/mipmap-*/.
Foreground: assets/branding/app_icon.png
Background: flat color (#FFFFFF or school primary color)

## Changing Branding for a School
1. Replace files in assets/branding/ with school-specific assets
2. Run: flutter pub run flutter_launcher_icons
3. Run: flutter pub run flutter_native_splash:create
4. Build flavor: flutter build apk --flavor school_a

## Fonts
Declare fonts in pubspec.yaml.
Use AppTextStyles (core/theme/app_text_styles.dart) — never hardcode fontFamily in widgets.
Default font: Inter (clean, modern, free, widely supported).
